# 自动可视化

查询成功后自动选择图表。单个数值默认只在正文回答，用户明确要求指标卡片时才生成卡片；“只用文字”“不要图表”等明确要求会跳过可视化，多任务拆解和问题改写也保留该偏好。单个数值的原始结果可在前端执行细节中查看。首批包含指标卡片、时间折线、分类柱状、横向排名、环形构成，以及多系列折线、时间堆叠、散点和SQL分桶直方图。用户无需启用开关。

`query_hint` 将趋势粒度、完整聚合和分桶要求交给SQL生成与修复。`visualization_node` 在回答后、记忆保存前执行，只读取当前单路成功结果或已审核通过的子任务，最多生成两张图。规则选图不增加模型调用。Pydantic协议只传字段映射与结构化数据，前端使用固定ECharts模板。

空结果、系统截断、重复时间与系列、嵌套值、非有限数、过多分类会保留表格。时间不自动补零，也不推断缺失期间的实际值。多个指标拆图，未确认的单位不自动换算。分布查询由SQL分桶，避免用截断明细推断总体。图表记录来源任务，可在数据表和执行细节中核对。

REST响应和SSE节点事件均包含 `visualizations` 和 `visualization_notes`。最近会话记录保存自包含图表数据，重新打开时使用当时的结果。旧记录没有图表字段时正常显示文字。现有滚动摘要仍会淘汰较早轮次的详细记录。

在项目根目录打开两个PowerShell终端。

```powershell
# 终端一
conda activate askdata
cd E:\desktop\LLM_Project\askdata\backend
python -m uvicorn server.main:app --host 127.0.0.1 --port 8000

# 终端二
cd E:\desktop\LLM_Project\askdata\frontend
npm install
npm run dev
```

打开Vite打印的网址，通常为 http://localhost:5173 。模型服务沿用 `backend/.env`。使用默认电商数据源时，订单日期为2026年6月至8月。数据源由 `DATA_SOURCE_FILE` 决定，外部源请改问其真实字段和期间。

- “2026年6月1日至8月31日，按月统计已支付订单的实付金额，查看销售额变化。”应显示折线图。
- “按地区统计已支付订单实付金额合计。”应显示柱状图。
- “按商品名称统计已支付订单实付金额，取销售额最高的5种商品。”应显示横向排名。
- “各商品品类已支付订单实付金额占比是多少？”类别较少时显示环形图。
- “已支付订单实付金额合计是多少？”默认文字回答；“用指标卡片展示已支付订单实付金额合计”应显示指标卡片。
- “列出最近10条订单明细。”应显示表格。

若默认数据库尚不存在，再于backend目录执行 `python -m data.seed_demo_data`。此命令会重建演示表，只在确认需要重新生成演示数据时使用。

可在回复中展开数据表核对数值，使用下载按钮保存SVG，切换会话后重新打开检查图表恢复。

离线回归命令如下。

```powershell
# backend目录
python -X utf8 -m unittest test.test_visualization -v
# frontend目录
node --test test/chartOptions.test.js
npm run build
```

图表可视化由固定数据规则决定，遇到歧义会保留文字和表格。任意新领域的别名、时间粒度和聚合口径仍取决于其元数据及语义配置质量。
