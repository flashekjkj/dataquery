# 本轮评测相关变更

## SQL

- 使用已安装的DuckDB原生parser辨别单条SELECT（含WITH），没有引入新依赖。
- 只读连接关闭外部访问，配置内存和线程上限；单查询5秒中断。
- 用户SQL完整放入子查询，外层仅取101行，返回100行并据第101行判断系统截断。
- 用户自己LIMIT 100得到100行不算系统截断；子查询中的LIMIT不会关闭外层保护。
- 提取保留WITH、分号字面量、连续空格和换行注释；拒绝多语句而不静默只取第一句。
- 查询超时、安全拦截、模型服务失败不进入SQL修复循环。

## 计量

- ContextVar默认值不再是共享字典；HTTP开始、CLI独立调用分别建立用量上下文。
- 纯ASGI中间件等待整个响应体结束，再记录HTTP耗时与访问日志；保留X-Request-ID。
- 区分业务success、partial、clarification、degraded、failed与cancelled，SSE done不再等于业务成功。
- 工具执行失败显式写入状态；回答降级不再被记录为正常业务成功。
- Trace使用独立墙钟耗时，嵌套span不相加作为请求耗时。
- 禁用OpenAI SDK内层自动重试，仅保留已计量的外层重试，避免隐藏的重试倍增。
- 配置温度默认0；提供可注入业务时钟，评测中固定为2026-10-29。

## 评测

- 开发集暴露并修正：销售Skill遗漏商品表、日期问题的时间角色字段未召回。
- 当前LangGraph通过name/metadata提供节点名，回调增加兼容处理；真实图验证不再全部记录unknown。

- 独立合成夹具与42题候选标注；标准SQL及预期结果不传给模型。
- 显式离线回归入口，不再依赖unittest自动发现普通函数测试。
- 对照保留修复前6题真实API结果，以及6项定向语义检查的前后记录。
- 冻结采用源码/输入hash清单和可恢复ZIP，避免未提交工作树与Git HEAD不一致。

这不是完整的企业级安全改造。数据库表级授权、全链路取消、跨进程持久化等仍在既有范围之外。
